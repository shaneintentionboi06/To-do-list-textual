# TO DO List
This Program is a simple To Do List app made using textual and sqlite, so it is a TUI based app.

## Getting Started

0. ### Get git and auth with GitHub. (If not Already) 
    refer to [Git SCM](https://git-scm.com/install/)
1. ### Clone This Repository
    Go to the Directory where you want to store this repository and run 
    ```git clone https://github.com/shaneintentionboi06/To-do-list-textual.git```

2. ### Install `uv` and sync packages
    install uv (Package Manager)
```pip install uv ``` <br>
    sync all packages
```uv sync```
3. ### Run the Program
``` uv run main.py ```

## Prerequisites

   * [Textual](https://github.com/Textualize/textual)
